# Siteholder site – notes for Claude

Static site for Siteholder Records. This repo is public (GitHub Pages): keep private notes out of it. Full project notes live in the claude.ai Project "Siteholder Website".

- Repo: brianffar/siteholder, branch main. Push to main deploys to https://siteholderrecords.com (GitHub Pages + Cloudflare). Tell Brian to hard refresh (Cmd+Shift+R) after pushes.
- Commit messages end with the Co-Authored-By and Claude-Session lines. Commit and push before ending a session. Use a wip branch for anything not ready to go live.
- Everything is in index.html (hash router, no build). Release data is embedded JSON. route() ends with enhanceSearch(); initCarousel(); fitHero();
- Home carousel: We're Back -> Latest release -> Featured artist; auto-rotates every 8s. Artists page uses FEATURED + FEAT_IMG; carousel uses HOME_ARTISTS.
- admin/ holds the private tools (all behind one Cloudflare Access rule on /admin): admin/social (reel and image generator), admin/previews (Preview Clipping Tool), admin/health (Catalog Health; admin/health/media-manifest.json is a hand-refreshed list of reel/image URLs from the sheet for its R2 check), admin/insights (IG Insights page; reads /admin/api/insights from the Cloudflare Worker in workers/insights, which holds the Instagram token as a secret, never in this repo), admin/calendar (Posting Calendar; reads admin/calendar/schedule-snapshot.json, a hand-refreshed copy of the Master Sheet Avery tab). The old /social and /previews are redirect stubs. go/ is the public smart link pages (edit go/links.json, then run python3 go/build.py: it rebuilds go/ and refreshes the STORE-LINKS block in index.html).
- Audio and media are on Cloudflare R2 (audio.siteholderrecords.com); the sandbox cannot reach it.
- Brian wants direct step-by-step instructions. Mockup first, then approval, then push; small content edits can be pushed directly.
- Calendar captions (LIVE, set up 2026-10-21): admin/calendar reads and saves captions via /admin/api/captions (Worker siteholder-captions, workers/captions/, route siteholderrecords.com/admin/api/captions*, secrets SHEET_URL + SHEET_SECRET) which calls the Apps Script web app "Siteholder Caption API" (apps-script/captions.gs, standalone, Script property SECRET). Saves write to Releases!Q (releases), Artists!O (spotlights) or Avery!K (announcements). Posted rows are locked. Covered by the Access path admin/*.
- Reel maker upload (2026-10-22): optional checkbox (off by default; single and batch; hidden on On this day) uploads reel + image to R2 via Worker siteholder-captions route /admin/api/media* (R2 binding MEDIA), then Apps Script action "reel" writes Releases!S (releases) or Outreach!C+D (artists) and flips Draft rows to Scheduled when reel + caption exist. Calendar overlays live reel/status from the sheet.
