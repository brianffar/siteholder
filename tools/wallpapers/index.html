Wallpapers

Six desktop wallpapers in the Siteholder pattern. Free to download and share.

All six, MacBook size (2880 × 1800) All six, 4K size (3840 × 2160)

Rotate them on a Mac

  1. Download a zip and open it, then keep the folder somewhere permanent.
  2. Open System Settings → Wallpaper.
  3. Choose Add Folder and pick that folder.
  4. Set how often it changes, such as every hour or every day.

The MacBook size fits any Mac laptop. Use the 4K size for a 16:9 or 4K monitor.
